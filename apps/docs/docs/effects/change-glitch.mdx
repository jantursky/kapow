---
title: "Change: glitch"
description: An element splits into offset color channels and shifted slices for a moment when a value changes.
---

Glitch makes the element look like a broken signal for a moment: its red, green and blue channels pull apart, horizontal slices jump sideways, and then everything snaps back. Use it for an error that repeats, a failed payment or a rejected code, where a shake would be too familiar.

## Usage

The sample glitches an error toast each time another attempt fails.

```kotlin
import androidx.compose.foundation.background
import androidx.compose.foundation.layout.padding
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.foundation.text.BasicText
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.clip
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.text.TextStyle
import androidx.compose.ui.unit.dp
import com.jantursky.kapow.ChangeEffect
import com.jantursky.kapow.changeEffect

@Composable
fun ErrorToast(failures: Int) {
    BasicText(
        text = "Payment failed. Try again.",
        style = TextStyle(color = Color.White),
        modifier = Modifier
            .changeEffect(failures, ChangeEffect.glitch(offset = 8.dp))
            .clip(RoundedCornerShape(10.dp))
            .background(Color(0xFF161616))
            .padding(horizontal = 16.dp, vertical = 12.dp),
    )
}
```

## Parameters

| Parameter | Default | Description |
| --- | --- | --- |
| `duration` | `300.milliseconds` | How long the glitch lasts. Must be positive. |
| `offset` | `6.dp` | How far the color channels split apart. Slices jump up to one and a half times as far. Must not be negative; 0 keeps the element in place and only redraws it. |

## Reduced motion

Nothing splits or shifts. The element brightens briefly.

## Notes

- The look changes every 50 ms: a new split and a new set of slices, about half of which jump. The pattern comes from a seed, so it is the same on every run and every platform.
- The element is drawn once into a layer of its own, and that layer is drawn again for each slice and channel. The copies are added together in an offscreen buffer, which rebuilds the original wherever they line up. No shader is involved, so it works on Android 6.
- Nothing is drawn outside the element's bounds: slices that jump are cut off at its edges, and the gaps they leave show what is behind the element.
- Semi-transparent edges, such as anti-aliased text on a transparent background, can look slightly darker while the glitch runs.
- There is no cooldown. A change during a glitch starts a new one.
