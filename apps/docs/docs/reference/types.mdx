All types are in `com.jantursky.kapow`. The effect classes have internal constructors: you create effects only through the factories on their companions, which lets future versions add effects and parameters without breaking binary compatibility. Effects are compared by value, so creating one inline in a composable is fine.

## ChangeEffect

An effect that plays once each time a watched value changes. Attach it with `Modifier.changeEffect`.

```kotlin
public abstract class ChangeEffect {
    public fun delay(delay: Duration): ChangeEffect

    public companion object {
        public fun spray(particles: ParticleContent = ParticleContent.shape(), count: Int = 11): ChangeEffect
        public fun rise(particles: ParticleContent = ParticleContent.text("+1")): ChangeEffect
        public fun shine(angle: Float = 45f, duration: Duration = 1.seconds, color: Color = Color.White): ChangeEffect
        public fun pulse(
            shape: Shape = RectangleShape,
            color: Color = Color(0xFF6B62F2),
            style: PulseStyle = PulseStyle.Stroke(),
            count: Int = 1,
        ): ChangeEffect
        public fun glow(color: Color = Color(0xFF6B62F2), radius: Dp = 16.dp, shape: Shape = RectangleShape): ChangeEffect
        public fun spin(axis: SpinAxis = SpinAxis.Y, rate: SpinRate = SpinRate.Default): ChangeEffect
        public fun confettiPop(colors: List<Color> = ParticleContent.DefaultColors, count: Int = 28): ChangeEffect
        public fun trace(
            shape: Shape = RectangleShape,
            color: Color = Color(0xFF6B62F2),
            width: Dp = 3.dp,
            duration: Duration = 1.seconds,
        ): ChangeEffect
        public fun strike(color: Color = Color(0xFF6B62F2), width: Dp = 2.dp, hold: Duration = 600.milliseconds): ChangeEffect
        public fun stamp(scale: Float = 1.3f, dustColor: Color = Color(0xFFB0B0B0)): ChangeEffect
        public fun glitch(duration: Duration = 300.milliseconds, offset: Dp = 6.dp): ChangeEffect
        public fun ripple(
            color: Color = Color(0x66FFFFFF),
            shape: Shape = RectangleShape,
            origin: TransformOrigin = TransformOrigin.Center,
            duration: Duration = 600.milliseconds,
        ): ChangeEffect
        public fun flash(color: Color = Color.White, duration: Duration = 400.milliseconds): ChangeEffect
        public fun burst(color: Color = Color(0xFFFFB547), spikes: Int = 12): ChangeEffect
        public fun speedLines(color: Color = Color(0xFF6B62F2), count: Int = 12): ChangeEffect
        public fun sparkle(color: Color = Color.White, count: Int = 6): ChangeEffect
        public fun fireworks(colors: List<Color> = ParticleContent.DefaultColors, count: Int = 28): ChangeEffect
    }
}
```

| Member | Description |
| --- | --- |
| `delay(delay)` | Plays this effect `delay` after the change instead of right away. `delay` must not be negative. |
| `spray(particles, count)` | A burst of `count` particles that fan upward from the element, grow, then fade. |
| `rise(particles)` | One particle per change, such as a "+1", that floats up from the element and fades. |
| `shine(angle, duration, color)` | A soft band of light that sweeps across the element's drawn pixels. `angle` is in degrees clockwise from pointing right, and 45 sweeps from the top left to the bottom right. |
| `pulse(shape, color, style, count)` | Rings or fills in `shape` that grow outward behind the element and fade. A change sends `count` pulses, 0.2 s apart. |
| `glow(color, radius, shape)` | A colored halo in `shape` that flares up and fades. Quick repeated changes make it stronger, up to a limit. |
| `spin(axis, rate)` | Spins the element one or more full turns and settles where it started. Changes mid-spin add speed. |
| `confettiPop(colors, count)` | A short pop of `count` confetti pieces in `colors` that burst from the element, tumble and fall away. |
| `trace(shape, color, width, duration)` | A comet-like stroke that runs once around the outline of `shape`, clockwise from the top, then disappears. |
| `strike(color, width, hold)` | A line that draws across the middle of the element, stays for `hold`, then fades out. |
| `stamp(scale, dustColor)` | Drops the element from `scale` times its size like a rubber stamp, with a squash on impact and dust at its base. `scale` must be at least 1. |
| `glitch(duration, offset)` | Splits the element into offset color channels and shifts horizontal slices of it for `duration`, then snaps back. |
| `ripple(color, shape, origin, duration)` | An ink ripple that spreads from `origin` across the element, inside `shape`, and fades. |
| `flash(color, duration)` | The element's own pixels flash `color` and fade back. |
| `burst(color, spikes)` | A comic star burst with `spikes` points pops out behind the element and fades. `spikes` is at least 3. |
| `speedLines(color, count)` | `count` comic action lines fly outward from the element's edges and vanish. |
| `sparkle(color, count)` | `count` four-point stars twinkle over the element, one after another. |
| `fireworks(colors, count)` | A spark climbs from the element, then bursts into `count` sparks that fall and fade. |

### PulseStyle, SpinAxis, SpinRate

```kotlin
public sealed class PulseStyle {
    public data class Stroke(val width: Dp = 2.dp) : PulseStyle()
    public data object Fill : PulseStyle()
}

public enum class SpinAxis { X, Y, Z }

public enum class SpinRate { Default, Fast }
```

`PulseStyle` chooses whether `pulse` draws rings or filled shapes. `SpinAxis.Y` turns like a coin on a table and `Z` like a wheel.

## ConditionalEffect

An effect that stays on while a condition is true. Attach it with `Modifier.conditionalEffect`.

```kotlin
public abstract class ConditionalEffect {
    public companion object {
        public val MinRepeatInterval: Duration

        public fun repeat(effect: ChangeEffect, every: Duration): ConditionalEffect
        public fun glow(color: Color = Color(0xFF6B62F2), radius: Dp = 16.dp, shape: Shape = RectangleShape): ConditionalEffect
        public fun pushDown(scale: Float = 0.95f): ConditionalEffect
        public fun smoke(color: Color = Color(0xFF8A8A8A)): ConditionalEffect
        public val RainbowColors: List<Color>
        public val FlameColors: List<Color>
        public fun borderBeam(
            color: Color = Color(0xFF6B62F2),
            width: Dp = 2.dp,
            shape: Shape = RectangleShape,
            length: Float = 0.25f,
            duration: Duration = 2.seconds,
        ): ConditionalEffect
        public fun marchingAnts(
            color: Color = Color.White,
            gapColor: Color = Color.Black,
            width: Dp = 2.dp,
            shape: Shape = RectangleShape,
            dash: Dp = 6.dp,
            gap: Dp = 4.dp,
            speed: Dp = 24.dp,
        ): ConditionalEffect
        public fun rainbowBorder(
            colors: List<Color> = RainbowColors,
            width: Dp = 3.dp,
            shape: Shape = RectangleShape,
            duration: Duration = 3.seconds,
        ): ConditionalEffect
        public fun sparkles(
            colors: List<Color> = listOf(Color(0xFFFFF1C2), Color(0xFFFFB547)),
            size: Dp = 18.dp,
            count: Int = 4,
        ): ConditionalEffect
        public fun orbit(
            colors: List<Color> = ParticleContent.DefaultColors,
            count: Int = 3,
            size: Dp = 8.dp,
            duration: Duration = 2.5.seconds,
        ): ConditionalEffect
        public fun bubbles(color: Color = Color(0xFF9ED8FF), size: Dp = 10.dp): ConditionalEffect
        public fun flame(colors: List<Color> = FlameColors, height: Dp = 40.dp): ConditionalEffect
        public fun grayscale(amount: Float = 1f): ConditionalEffect
        public fun spotlight(
            color: Color = Color(0x99000000),
            shape: Shape = RectangleShape,
            padding: Dp = 8.dp,
            softness: Dp = 24.dp,
        ): ConditionalEffect
    }
}
```

| Member | Description |
| --- | --- |
| `MinRepeatInterval` | The shortest interval `repeat` accepts, 1/15 s. Shorter ones are raised to it. |
| `repeat(effect, every)` | Plays `effect` as soon as the condition turns true, then every `every` while it stays true. |
| `glow(color, radius, shape)` | A steady halo in `shape` that fades in while the condition holds. |
| `pushDown(scale)` | Scales the element down slightly, as if pressed, and springs back when the condition ends. `scale` must be positive. |
| `smoke(color)` | Soft particles that rise from the top of the element, like smoke. |
| `borderBeam(color, width, shape, length, duration)` | A bright segment, `length` of the outline long, travels around `shape` once every `duration`. |
| `marchingAnts(color, gapColor, width, shape, dash, gap, speed)` | A dashed outline around `shape` whose dashes move, like a selection. |
| `rainbowBorder(colors, width, shape, duration)` | An outline stroked with a sweep gradient of `colors` that turns once every `duration`. |
| `sparkles(colors, size, count)` | Four-point stars keep twinkling over and around the element, about `count` at a time. |
| `orbit(colors, count, size, duration)` | `count` particles circle the element on an ellipse, smaller and fainter behind it. |
| `bubbles(color, size)` | Small bubbles keep rising from the top edge, wobbling and fading. |
| `flame(colors, height)` | Procedural flames about `height` tall above the element. |
| `grayscale(amount)` | The element desaturates by `amount`, from 0 to 1. |
| `spotlight(color, shape, padding, softness)` | Everything around the element dims with `color`, leaving `shape` plus `padding` lit, with a soft edge. Later siblings still draw on top. |

## ProgressEffect

An effect drawn at a progress you control, from 0 to 1. Attach it with `Modifier.progressEffect` or `Modifier.hingeEffect`.

```kotlin
public abstract class ProgressEffect {
    public companion object {
        public fun shine(angle: Float = 45f, color: Color = Color.White): ProgressEffect
        public fun glow(color: Color = Color(0xFF6B62F2), radius: Dp = 16.dp, shape: Shape = RectangleShape): ProgressEffect
        public fun iris(origin: TransformOrigin = TransformOrigin.Center): ProgressEffect
        public fun fill(color: Color = Color(0x993D7BFF), wave: Dp = 4.dp): ProgressEffect
        public fun trace(shape: Shape = RectangleShape, color: Color = Color(0xFF6B62F2), width: Dp = 3.dp): ProgressEffect
    }
}
```

| Member | Description |
| --- | --- |
| `shine(angle, color)` | A band of light whose position across the element follows the progress. |
| `glow(color, radius, shape)` | A halo whose strength follows the progress. |
| `iris(origin)` | A circular reveal from `origin` whose radius follows the progress. |
| `fill(color, wave)` | A liquid in `color` that fills the element's pixels from the bottom up to the progress, with a wave `wave` high on its surface. |
| `trace(shape, color, width)` | The outline of `shape` drawn as a stroke, clockwise from the top, up to the progress. |

## KapowEnter

How content appears inside an `AnimatedVisibility` or `AnimatedContent`. Apply it with `Modifier.kapowTransition` or `KapowAnimatedVisibility`.

```kotlin
public class KapowEnter {
    public companion object {
        public val None: KapowEnter

        public fun iris(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 450.milliseconds): KapowEnter
        public fun clock(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 450.milliseconds): KapowEnter
        public fun wipe(angle: Float = 0f, duration: Duration = 450.milliseconds): KapowEnter
        public fun glare(angle: Float = 45f, color: Color = Color.White, duration: Duration = 450.milliseconds): KapowEnter
        public fun blinds(
            slatWidth: Dp = 10.dp,
            orientation: BlindsOrientation = BlindsOrientation.Horizontal,
            staggered: Boolean = false,
            duration: Duration = 450.milliseconds,
        ): KapowEnter
        public fun anvil(duration: Duration = 1400.milliseconds): KapowEnter
        public fun pop(color: Color = Color(0xFF6B62F2), duration: Duration = 1200.milliseconds): KapowEnter
        public fun dissolve(cellSize: Dp = 12.dp, duration: Duration = 600.milliseconds): KapowEnter
        public fun curtain(
            orientation: BlindsOrientation = BlindsOrientation.Vertical,
            duration: Duration = 450.milliseconds,
        ): KapowEnter
        public fun shapeIris(
            shape: Shape = StarShape(),
            origin: TransformOrigin = TransformOrigin.Center,
            duration: Duration = 600.milliseconds,
        ): KapowEnter
        public fun checker(cellSize: Dp = 24.dp, duration: Duration = 600.milliseconds): KapowEnter
        public fun tear(angle: Float = 0f, toothSize: Dp = 12.dp, duration: Duration = 500.milliseconds): KapowEnter
        public fun blob(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 600.milliseconds): KapowEnter
    }
}
```

| Member | Description |
| --- | --- |
| `None` | No Kapow transition. Content appears with whatever stock transition the caller set. |
| `iris(origin, duration)` | A circle that grows from `origin` until it covers the content. |
| `clock(origin, duration)` | A sweep around `origin`, clockwise from 12 o'clock, like a clock hand. |
| `wipe(angle, duration)` | A straight edge that moves across the content in the direction of `angle` (degrees, 0 is rightward). |
| `glare(angle, color, duration)` | A `wipe` with a bright streak of `color` running along its edge. |
| `blinds(slatWidth, orientation, staggered, duration)` | Slats that open like venetian blinds. With `staggered`, slats nearer the top (or start) open first. `slatWidth` is at least 5 dp. |
| `anvil(duration)` | The content drops in from above, lands with a shake and kicks up dust. |
| `pop(color, duration)` | The content pops in with an overshoot while a ring and a burst of particles of `color` go off behind it. |
| `dissolve(cellSize, duration)` | The content appears as a random grid of squares `cellSize` wide. `cellSize` is at least 2 dp. |
| `curtain(orientation, duration)` | Two halves slide apart to reveal the content. |
| `shapeIris(shape, origin, duration)` | Like `iris`, through any `shape`, such as a `StarShape`, growing from `origin`. |
| `checker(cellSize, duration)` | A checkerboard of `cellSize` cells that fills in two waves. |
| `tear(angle, toothSize, duration)` | A `wipe` whose edge is a torn zigzag with teeth `toothSize` deep. |
| `blob(origin, duration)` | An organic wobbly blob that grows from `origin` until it covers the content. |

Every `duration` must be positive.

## KapowExit

How content disappears inside an `AnimatedVisibility` or `AnimatedContent`. Mask transitions run the reverse of their `KapowEnter` counterpart.

```kotlin
public class KapowExit {
    public companion object {
        public val None: KapowExit

        public fun iris(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 450.milliseconds): KapowExit
        public fun clock(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 450.milliseconds): KapowExit
        public fun wipe(angle: Float = 0f, duration: Duration = 450.milliseconds): KapowExit
        public fun glare(angle: Float = 45f, color: Color = Color.White, duration: Duration = 450.milliseconds): KapowExit
        public fun blinds(
            slatWidth: Dp = 10.dp,
            orientation: BlindsOrientation = BlindsOrientation.Horizontal,
            staggered: Boolean = false,
            duration: Duration = 450.milliseconds,
        ): KapowExit
        public fun poof(color: Color = Color(0xFFC2C2C2), duration: Duration = 400.milliseconds): KapowExit
        public fun dissolve(cellSize: Dp = 12.dp, duration: Duration = 600.milliseconds): KapowExit
        public fun curtain(
            orientation: BlindsOrientation = BlindsOrientation.Vertical,
            duration: Duration = 450.milliseconds,
        ): KapowExit
        public fun shapeIris(
            shape: Shape = StarShape(),
            origin: TransformOrigin = TransformOrigin.Center,
            duration: Duration = 600.milliseconds,
        ): KapowExit
        public fun checker(cellSize: Dp = 24.dp, duration: Duration = 600.milliseconds): KapowExit
        public fun tear(angle: Float = 0f, toothSize: Dp = 12.dp, duration: Duration = 500.milliseconds): KapowExit
        public fun blob(origin: TransformOrigin = TransformOrigin.Center, duration: Duration = 600.milliseconds): KapowExit
        public fun shatter(shards: Int = 24, duration: Duration = 900.milliseconds): KapowExit
        public fun disintegrate(color: Color = Color.Unspecified, duration: Duration = 1500.milliseconds): KapowExit
    }
}
```

| Member | Description |
| --- | --- |
| `None` | No Kapow transition. Content disappears with whatever stock transition the caller set. |
| `iris(origin, duration)` | A circle that shrinks toward `origin`. |
| `clock(origin, duration)` | A sweep around `origin` that takes the content away, counterclockwise back to 12 o'clock. |
| `wipe(angle, duration)` | A straight edge that covers the content, moving against `angle`. |
| `glare(angle, color, duration)` | A `wipe` with a bright streak of `color` along its edge. |
| `blinds(slatWidth, orientation, staggered, duration)` | Slats that close like venetian blinds. |
| `poof(color, duration)` | The content vanishes at once in a puff of smoke of `color`. |
| `dissolve(cellSize, duration)` | The content vanishes as a random grid of squares. |
| `curtain(orientation, duration)` | Two halves slide shut over the content. |
| `shapeIris(shape, origin, duration)` | Like `iris`, through any `shape`, shrinking toward `origin`. |
| `checker(cellSize, duration)` | A checkerboard that empties in two waves. |
| `tear(angle, toothSize, duration)` | A torn-edge `wipe` that covers the content. |
| `blob(origin, duration)` | An organic blob that shrinks toward `origin`. |
| `shatter(shards, duration)` | The content breaks into `shards` triangular pieces that fall, turn and fade. |
| `disintegrate(color, duration)` | A band sweeps across and turns the content into drifting dust, in the content's colors where the platform can read them, otherwise in `color` or light gray. |

### BlindsOrientation

```kotlin
public enum class BlindsOrientation { Horizontal, Vertical }
```

The direction of the slats in `blinds` and of the split in `curtain`.

### StarShape

```kotlin
public class StarShape(points: Int = 5, innerRatio: Float = 0.5f) : Shape
```

A star with `points` points whose inner corners sit at `innerRatio` of the outer radius. The default mask of `shapeIris`, and usable anywhere a `Shape` is.

## ParticleContent

What a particle effect draws for each particle.

```kotlin
public sealed class ParticleContent {
    public companion object {
        public val DefaultColors: List<Color>

        public fun shape(
            shape: ParticleShape = ParticleShape.Sparkle,
            colors: List<Color> = DefaultColors,
            size: Dp = 14.dp,
        ): ParticleContent
        public fun painter(painter: Painter, size: Dp = 18.dp, tint: Color? = null): ParticleContent
        public fun text(text: String, style: TextStyle = TextStyle(/* amber, 16 sp, semibold */)): ParticleContent
    }
}

public enum class ParticleShape { Circle, Square, Star, Heart, Sparkle }
```

| Member | Description |
| --- | --- |
| `DefaultColors` | Warm amber, coral, violet and cobalt. |
| `shape(shape, colors, size)` | A `ParticleShape`, colored from `colors` in turn. `colors` must not be empty. |
| `painter(painter, size, tint)` | A `Painter` drawn at `size`, optionally tinted. Remember the painter so it is not recreated. |
| `text(text, style)` | A short label such as "+1". |

## Reduced motion

```kotlin
public enum class KapowMotion { System, Full, Reduced }

public val LocalKapowMotion: ProvidableCompositionLocal<KapowMotion>
```

`LocalKapowMotion` overrides the reduced-motion setting for part of the tree. It defaults to `KapowMotion.System`, which follows the platform. `Full` always plays full effects. `Reduced` always plays the reduced version. See [Reduced motion](/guides/reduced-motion).

## Feedback

```kotlin
public fun interface KapowFeedback {
    public fun perform(event: KapowFeedbackEvent)
}

public sealed class KapowFeedbackEvent {
    public data object Selection : KapowFeedbackEvent()
    public data object ImpactLight : KapowFeedbackEvent()
    public data object ImpactMedium : KapowFeedbackEvent()
    public data object ImpactHeavy : KapowFeedbackEvent()
    public data object Success : KapowFeedbackEvent()
    public data object Warning : KapowFeedbackEvent()
    public data object Error : KapowFeedbackEvent()
    public data class Custom(val name: String) : KapowFeedbackEvent()
}

public val LocalKapowFeedback: ProvidableCompositionLocal<KapowFeedback?>
```

`KapowFeedback` plays haptic or sound feedback when an effect fires. Kapow does not make haptics itself. `LocalKapowFeedback` is the handler for a part of the tree, and `null`, the default, plays nothing. `Custom` carries an event your own handler understands, such as a sound named `"coin"`. See [Feedback](/guides/feedback).
