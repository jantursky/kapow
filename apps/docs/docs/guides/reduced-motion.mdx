---
title: Reduced motion
description: How Kapow reads the platform's reduced-motion setting on each target, what every effect does instead, and how to override it.
---

Some people turn motion off because it makes them ill or because they find it distracting. Kapow follows that setting on every platform and swaps each effect for a quiet version: a short fade or highlight, with no particles and no movement.

You do not have to call anything. Change and conditional effects check the setting each time they start; transitions check it when they compose.

## Where the setting comes from

| Target | Source |
| --- | --- |
| Android | `ValueAnimator.areAnimatorsEnabled()` on API 26 and later. Below API 26, Compose's `MotionDurationScale`, which is 0 when animations are off. That scale is read on all versions. |
| iOS | Reduce Motion in Accessibility settings. Compose also reports it as a motion duration scale of 0. |
| wasmJs | The `prefers-reduced-motion: reduce` media query. |
| JVM desktop | No system source. Motion is full unless you override it. |

On Android, both checks matter. Turning "Remove animations" on sets the animator duration scale to 0, and Compose passes that scale to coroutines as `MotionDurationScale`. Kapow treats a scale of 0 as reduced motion even on versions where the platform call is not available.

## What each effect does instead

| Effect | With reduced motion |
| --- | --- |
| `spray`, `rise` | No particles. The element briefly brightens. |
| `smoke` | Nothing. |
| `spin` | No rotation. The element briefly brightens. |
| `pulse` | No rings. The element's area flashes in the pulse color and fades. |
| `shine` | No sweep. A brief highlight that fades out. |
| `glow` | A faint, short halo that does not pulse. |
| Conditional `glow` | The steady halo appears without a fade. |
| `confettiPop` | No confetti. The element briefly brightens. |
| `trace` | Nothing travels. The whole outline appears at once and fades. |
| `strike` | The line appears whole instead of drawing across, then holds and fades. |
| `stamp` | No drop, no squash and no dust. The element briefly brightens. |
| Mask transitions: `iris`, `clock`, `wipe`, `glare`, `blinds` | A crossfade over the same duration or shorter, with no mask. |
| `poof`, `anvil`, `pop` | A fade over the same duration or shorter. No particles, no drop, no scale. |

Feedback calls are not affected. A haptic you asked for still fires under reduced motion.

The [effects pages](/effects) list the reduced behavior of every effect, including `repeat`, `pushDown` and the progress effects.

## Overriding the setting

`LocalKapowMotion` overrides the platform for a part of the tree. It has three values:

- `KapowMotion.System`, the default, follows the platform.
- `KapowMotion.Full` always plays full effects.
- `KapowMotion.Reduced` always plays the reduced version.

```kotlin
import androidx.compose.runtime.Composable
import androidx.compose.runtime.CompositionLocalProvider
import com.jantursky.kapow.KapowMotion
import com.jantursky.kapow.LocalKapowMotion

@Composable
fun MotionSettings(reduceMotion: Boolean, content: @Composable () -> Unit) {
    CompositionLocalProvider(
        LocalKapowMotion provides if (reduceMotion) KapowMotion.Reduced else KapowMotion.System,
        content = content,
    )
}
```

On JVM desktop there is nothing to follow, so this is the way to offer an in-app switch. Use `Reduced` in tests to check the quiet path.

If you override to `Full`, you are playing motion for a user who asked for none. Do it for a preview or a demo, not for the app.

## Reading it yourself

`isReducedMotion()` is a composable that returns the value effects here would use. It resolves `LocalKapowMotion` first, then the platform. Use it to match your own animations to Kapow's.

```kotlin
import androidx.compose.runtime.Composable
import com.jantursky.kapow.isReducedMotion

@Composable
fun rememberCardDuration(): Int = if (isReducedMotion()) 0 else 300
```

The Android, iOS and browser detection is covered by tests and by running the demo. Reading the Reduce Motion setting on a real iPhone has not been checked, and neither has wasm in Safari.
