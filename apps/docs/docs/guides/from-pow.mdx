---
title: Coming from Pow
description: Every Pow effect and transition mapped to the Kapow API that comes closest, with the ones Kapow does not have and why.
---

Kapow is inspired by [Pow](https://github.com/EmergeTools/Pow) for SwiftUI and takes its three groups, change effects, conditional effects and transitions. This page lists each Pow effect and transition from Pow's repository, with the Kapow factory that comes closest. Where Kapow has no counterpart, the last column says why and what to do instead.

Matches are close, not exact. Pow's parameters are not always Kapow's, and a port should be compared on a device before it ships.

## Change effects

| Pow | Kapow | Notes |
| --- | --- | --- |
| `spray` | [`ChangeEffect.spray`](/effects/change-spray) | Particles that rise from an origin. |
| Haptic feedback (`feedback(hapticNotification:)`, `feedback(hapticImpact:)`) | `feedback` parameter of `changeEffect`, see [feedback](/guides/feedback) | Kapow sends an event; the app turns it into a haptic. |
| `jump` | [`ChangeEffect.jump`](/effects/change-jump) | |
| `ping` | [`ChangeEffect.pulse`](/effects/change-pulse) | Rings that grow and fade behind the element. Kapow also has a [conditional ping](/effects/conditional-ping) for an effect that runs while a state holds. |
| `rise` | [`ChangeEffect.rise`](/effects/change-rise) | Needs `KapowParticleLayer` above clipping parents, see [particle layer](/guides/particle-layer). |
| `shake` | [`ChangeEffect.shake`](/effects/change-shake) | |
| `shine` | [`ChangeEffect.shine`](/effects/change-shine) | |
| `spin` | [`ChangeEffect.spin`](/effects/change-spin) | |
| `delay` | [`ChangeEffect.delay`](/effects/change-delay) | Also `KapowEnter.delay` and `KapowExit.delay` on transitions. |
| Sound effect feedback (`feedback(_:)` with a `SoundEffect`) | No counterpart | Kapow ships no audio. Play your own sound from the handler of the `feedback` event. |

## Transitions

| Pow | Kapow | Notes |
| --- | --- | --- |
| `anvil` | [`KapowEnter.anvil`](/effects/transition-anvil) and `KapowExit.anvil` | |
| `blinds` | [`KapowEnter.blinds`](/effects/transition-blinds) and `KapowExit.blinds` | |

| `flip` | [`KapowEnter.rotate3D`](/effects/transition-rotate3d) and `KapowExit.rotate3D` | Closest: Kapow's 3D rotation takes an axis and a camera distance. |

| `vanish` | [`KapowExit.disintegrate`](/effects/transition-disintegrate) | Pow removes the view into particles. Kapow's disintegrate does the same on exit. |

## Particle layer

Pow's `layer` parameter (`.local` or a shared layer) has no direct switch in Kapow. An effect draws in the nearest [`KapowParticleLayer`](/guides/particle-layer) above it, or around its own element when there is none.
