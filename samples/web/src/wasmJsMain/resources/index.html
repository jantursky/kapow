Effects

compose multiplatform

Effects that fire when something changes.

Kapow adds one-shot effects for changed values, effects that run while a condition holds, and masked or particle transitions for AnimatedVisibility. It runs on Android, iOS, desktop and the web, and every frame is drawn without recomposing.

Pick an effect in the list to see it run, change its parameters and read the code that makes it. The meter in the bar shows what the page costs, and the motion switch shows how each effect reduces itself.
